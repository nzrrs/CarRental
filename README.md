# CarRentalApp

## Basic Idea

CarRentalApp is a web-based system designed to manage vehicle rentals in a simple and structured way. It allows users to browse available cars, view details, and handle booking operations through a connected API.

---

## Setup

### Requirements

| Tool | Purpose |
|------|--------|
| Node.js | Runs the client application |
| PHP | Runs the server application |
| Composer | Manages server dependencies |
| MySQL | Stores application data |

---

### Steps

1. Install dependencies for both environments  
2. Configure environment variables  
3. Initialize and migrate the database  
4. Start the backend service  
5. Start the frontend application  
6. Connect both through API endpoints
